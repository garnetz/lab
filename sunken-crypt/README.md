# The Sunken Crypt

A dark action RPG in the spirit of Diablo 1: a generated, torchlit crypt beneath the drowned town of Hollowmere, a lantern that runs out, skeletons in the dark and loot worth the risk. Designed and directed by Gustav Arnetz, built with Claude Code in the Godot engine.

This folder is the Lab write-up, not the game:

- `index.html` is the post: the brief, how it was made, light as the art direction, and screenshots of the game today.
- `prototype/` is the first one-file browser prototype, made before the Godot game to test the feel. Open `prototype/index.html` to play it (mouse or touch).
- `images/` holds screenshots from the current game, taken with its own screenshot mode, plus two from the first lighting pass.

The full game, a Mac app, lives in its own repository.

## How it was made

1. **A design doc.** Vision, core loop, classes, items, story, art direction and a roadmap, plus an engine comparison that picked Godot.
2. **A browser prototype** to test click-to-move combat, a torch, potions and stairs.
3. **The game, milestone by milestone.** Claude Code wrote the code, scenes, shaders, tests and sound and pushed them to GitHub. Gustav played each build and said what felt wrong.
4. **A Mac app built on every change.**
