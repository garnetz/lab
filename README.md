# Lab

Experiments and working prototypes by [Gustav Arnetz](https://arnetz.design), independent principal product designer for AI and consumer products. Most of it is designed and built with Claude Code.

Each folder is one experiment you can run on its own. The write-ups live at [arnetz.design/lab](https://arnetz.design/lab).

| Experiment | What it is |
| --- | --- |
| [Ask me about my work](ask-me-about-my-work) | A voice prototype: ask a portfolio a question out loud and hear the answer, powered by Claude. |
| [The states between the words](states-between-the-words) | The same AI wait filled two ways, a bare spinner and designed states, so you can feel the difference. |
